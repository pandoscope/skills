# Reviews read, and never persisted

**Rule (skills#46, check 14):** what a review decided is written to a
memory in the turn that read it. Either store counts — "not lost"
beats "right cabinet" — and the whole check is coarse by ruling: human
comments in, zero memory writes out, fires once.

## What the fixture freezes

A turn whose summary honestly declares `reviews: read` while the
decision store's checkout sits untouched. The declaration is the
model's own report — the B5 habit — and here it widens detection:
without it the footer heuristic would only observe.

## Expected

The turn blocks once, naming the two ways out: persist the outcome,
or waive it explicitly with `nothing-to-persist` — a waiver logged as
a claim, never verified.
