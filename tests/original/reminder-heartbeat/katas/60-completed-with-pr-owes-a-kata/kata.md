# Completed with a PR, and no kata

**Rule (skills#46, check 10, ruling F11):** work that completes with
a PR owes the corpus a kata — the trigger is mechanical, the adequacy
is not, so the hook reminds exactly once per thread and afterwards
records only the claim. The fresh-incident moment is when a kata is
cheap; a reminder that re-fires until obeyed would be a blocking
check wearing a softer name.

## What the fixture freezes

A thread completing this turn with its `pr` field set, and no
reminder yet delivered for it.

## Expected

The turn blocks once with the kata prompt; the delivered set gains
the thread, so kata 61's turn — the same state one turn later —
seals.
