# A new thread was never announced

**Rule (skills#99):** when the model judges that a new thread of work
starts, it says so in prose — `new thread: <slug>` — and uses that name
from then on. The ledger knowing is not the reader knowing: the opened
event landed, the summary declares the thread, and the response never
told the principal a new line of work exists.

## What the fixture freezes

A turn that opened `hygiene-rollout` in the ledger and declared it in
the summary, whose response describes the work without ever announcing
the thread by name.

## Expected

Blocked once, with the exact announcement the rewrite must contain.
