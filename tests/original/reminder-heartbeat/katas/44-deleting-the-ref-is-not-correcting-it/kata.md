# Deleting the ref is not correcting it

**Rule (skills#99):** the correction is an exercise, and the exercise
is writing the canonical forms OUT — a rewrite that simply removes the
offending refs silences the scanner while learning nothing, so it does
not pass.

## What the fixture freezes

The second Stop of a turn whose first Stop assigned homework: the
pending-corrections file names the canonical form the rewrite must
contain, and the rewritten response dropped the ref instead. The loop
guard is up, as it is on every re-fire.

## Expected

The guard holds — one block per turn, always — so the turn is released
UNSEALED with `response-hygiene` as the check that failed. The seal gap
is the record: the exercise was assigned, graded, and not completed,
and the compliance log says so where diligence can count it.
