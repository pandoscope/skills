# A declared ticket never heard about its turn

**Rule (skills#46, check 4):** every ticket the turn declared gets an
observed write — an issue-writing tool call in the transcript — or an
explicit waiver. The declared set diffing against actual calls is the
whole design: self-report names the scope, observation judges it.

## What the fixture freezes

A summary declaring `tickets: o/r#61` over a transcript holding no
issue-write call at all — the four-turns-of-silent-drift class, aimed
at the forge instead of the ledger.

## Expected

The turn blocks once, naming the ticket and both ways out.
