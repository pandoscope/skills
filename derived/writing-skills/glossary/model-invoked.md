## Model-Invoked

A skill that keeps its `description`, so the agent finds and fires it on its own,
and other skills can reach it.
The human can still type its name — model-invocation adds agent reach, never removes human reach.
The description's mere presence *is* the invocation axis, and the source of the skill's
[context load](context-load.md).

_Avoid_: ability, tool, capability
