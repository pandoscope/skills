## Completion Criterion

The condition telling an agent a unit of work is done.
Two axes: *checkable* (can the agent tell done from not-done?) resists [premature completion](premature-completion.md),
and *demanding* ("every modified model accounted for" beats "produce a change list") sets [legwork](legwork.md).
The demand axis binds flat [reference](reference.md) too — "every rule applied".

_Avoid_: done condition, exit condition, stopping rule
