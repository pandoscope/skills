## Description

A skill's machine-readable trigger, and the one [context pointer](context-pointer.md)
a [model-invoked](model-invoked.md) skill keeps loaded at all times.
Its presence *is* the invocation axis: keep it and the agent can reach the skill,
drop it and the skill is [user-invoked](user-invoked.md).
