## Sprawl

*Failure mode.*
A skill simply too long, even when every line is live and unique —
length itself, not staleness ([sediment](sediment.md)) or repetition ([duplication](duplication.md)).
The agent wades through more before it can act, and attention thins across the excess.
Cure: push reference behind a [context pointer](context-pointer.md),
and split by branch or by sequence so each path carries only what it needs.

_Avoid_: bloat, length, verbosity
