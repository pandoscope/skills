# Markdown rules

These rules hold for Markdown files in a repository, skill files and files loaded into every session.

- `line-ref` [H] Refer to a passage by quoting its anchor text, not by its line number.
- `repo-link` [H] Link a file in the same repository by its relative path, so the link follows the branch, fork or clone being read.
- `glossary-marking` [H] Link the first mention of a glossary term, bold every later mention that means the term, and leave the everyday word unmarked.
